### What I actually do

I have over 7 years of experience of building backend systems end-to-end — from API design and service architecture down to database behavior, identity flows, deployment, and the operational failure modes nobody documents.

I treat software engineering as **the discipline of controlled complexity**. Code that works once is not the goal. Code that can be understood, tested, operated, debugged, extended, and trusted under real production conditions — that's the goal.

---

### How I think about systems

A system is not the happy path. It's everything around it: timeouts, retries, bad input, partial failure, async context leakage, thread-pool starvation, identity edge cases, schema drift, and the 3 AM page.

- [Horizontally Scalable i18n Demo](https://github.com/m-remis/horizontally-scallable-18n-demo)  
Spring Boot demo focused on dynamic internationalization and localization for external clients, designed around scalable backend-side translation management instead of hardcoded application text.
